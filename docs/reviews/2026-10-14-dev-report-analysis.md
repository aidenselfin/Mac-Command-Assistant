## 수정 범위

- `Planner.resume`: 파일을 선택해도 누적 답변·조건을 유지하고 모델의 user 메시지에 전달.
- 단독 `다시`/`retry`/`again`의 자유 입력 답변은 작업 자체를 제공한다. 기존 읽기 요청의
  답변에 삭제 지시가 들어가도 삭제 도구는 노출되지 않는다.
- 날짜·회의록·보고서·메모·예산안으로 지정한 삭제는 검색부터 시작한다. 정확한 파일명이
  원문에 없으면 후보가 하나여도 선택 질문으로 확인한다. 선택 뒤 별도 승인이 필요하다.
- 선택한 파일 외의 추가 대상은 거부한다. 대상 없는 포괄 삭제·기억만으로 지시한 삭제,
  허용 경계·승인·백업·Undo 정책은 유지한다.
- 사용자 자료 `voice-action-test/product.md`의 기존 삭제는 변경하거나 커밋하지 않는다.
