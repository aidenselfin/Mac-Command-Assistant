## 남은 문제

- 기존 DB에 이미 저장된 예전 형식 기록(도구 결과 앞 500자 등)은 소급 정제되지 않는다.
  사용자 소유 DB라 자동 삭제하지 않았다.
- assistant 응답 앞 300자는 저장·분석에 쓰인다. 응답이 파일 내용을 인용하면 그 일부가 남을 수 있다.
- SQLite `-wal`/`-shm` 보조 파일은 프로세스 umask 권한을 따른다. 경로 검사와 open 사이의 경합,
  journal 준비와 MCP write 사이의 외부 변경은 막지 못한다.
- R3/R4/R5는 "실패 확정"이 아닌 감지 신호다. 정상적인 반복 조회·거절·Undo도 분석 대상이 될 수 있어
  M5에서 오탐률 측정이 필요하다. clarification 답변도 user_input으로 기록된다.
- `UNSAFE_LESSON_PATTERN`은 키워드 필터일 뿐 prompt injection 방어가 아니다.
- event 정리와 lesson 만료는 실행 시작 때만 일어나고, incidents·비활성 lesson은 계속 쌓인다.

운영 평가(M5)는 lesson별 노출 run 수, 같은 signature 재발률, 오탐률, 시작한 분석 요청 수를 함께 본다.
