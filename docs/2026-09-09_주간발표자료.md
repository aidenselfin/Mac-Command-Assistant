# 4. 주요 기술적 과제 및 해결 방안 (Challenges & Solutions)

* **도구 스키마의 프로바이더 간 호환성 문제**:
  - *이슈*: OpenAI 함수 호출 스키마와 Anthropic Tool 스키마의 포맷 차이
  - *해결*: `mcp_client.py`에서 MCP 표준 스키마를 OpenAI(`parameters`)와 Anthropic(`input_schema`) 포맷으로 각각 자동 변환하는 어댑터 메서드 구현
* **비동기 이벤트 루프와 키보드 리스너 충돌**:
  - *이슈*: `pynput` 키보드 스레드와 `asyncio` 메인 이벤트 루프 간 블로킹 문제
  - *해결*: Push-to-Talk 릴리즈 시 백그라운드 스레드에서 `asyncio.run_coroutine_threadsafe`를 호출하여 메인 UI 스레드 락 방지
