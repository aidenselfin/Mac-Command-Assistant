UI 계획서 + Story Board 기반으로 정리한 단계별 표. 각 행은 사용자 행동 → UI 피드백 → 시스템 내부 처리 순서로 매칭됨.

사용자 행동 UI 피드백 시스템 내부 처리

0. 공통 5단계 (모든 시나리오 공유)

단계사용자 행동UI 피드백 (메뉴바 / 토스트)시스템 내부 처리
① 트리거R-cmd 꾹 누름메뉴바 빨강 ● "듣는 중…" + 하단 토스트 파형마이크 활성화, 오디오 캡처 시작
② 발화음성 명령 말함 → 손 뗌메뉴바 노랑 ● "받아쓰는 중…"faster-whisper / Apple STT → 텍스트 변환
③ 해석대기메뉴바 파랑 ● "생각 중…" + 토스트에 인식 문장 표시LLM이 action / target / params JSON 반환
④ 실행대기 / 결과 확인메뉴바 초록 ● "실행 중…"osascript / CGEvent / AXUIElement / CLI 호출
⑤ 완료작업 이어서 진행토스트 "✓ 완료 (소요 시간)" → 1.5초 후 페이드아웃, 메뉴바 회색 ●로그 저장, 패턴 분석 큐에 적재

시나리오 1 — 공부 모드 시작 (창 배치)

단계사용자 행동UI 피드백시스템 내부 처리
1R-cmd 길게 누름메뉴바 빨강 ● + 파형 토스트마이크 ON
2"기계학습 공부 모드 시작" 발화노랑 ● → 파랑 ● ("기계학습 공부 모드 시작")STT → LLM: action: restore_layout, mode: "기계학습공부"
3—초록 ● "실행 중…"프리셋 로드 → open -a "zoom.us", open -a "Google Chrome"
4—화면에서 Zoom·Chrome 차례로 배치되는 모습osascript set bounds of window 1 to {0,23,960,1080} / {960,23,1920,1080}, Chrome에 Notion URL open location
5바로 공부 시작토스트 "✓ 기계학습 공부 모드 적용 (1.8초)"대기 상태 복귀

시나리오 2 — 파일 정리

단계사용자 행동UI 피드백시스템 내부 처리
1"다운로드 폴더 열어줘"상태 인디케이터 진행open ~/Downloads
2"PDF 파일들 보여줘"화면에 파일 목록 번호 오버레이 [1][2][3]…find ~/Downloads -name "*.pdf" → AX 오버레이 렌더링
3"1번이랑 2번 Documents로 이동"토스트 진행 표시mv ~/Downloads/A.pdf ~/Documents/ ×2
4"3번 삭제해줘" → "응"확인 다이얼로그 "삭제할까요?"Finder move to trash (osascript)
5"2026 강의자료 폴더 만들고 강의 관련 파일 옮겨줘"대상 파일 후보 오버레이 + 확인mkdir + LLM 키워드 매칭 후 mv

시나리오 3 — 이메일 작성·전송

단계사용자 행동UI 피드백시스템 내부 처리
1"메일 앱 열어줘"초록 ● + 토스트open -a "Mail"

5"과제 파일 첨부" → "보내줘"전송 확인 + 완료 토스트mdfind 검색 → 첨부 → Cmd+Shift+D

시나리오 4 — 웹 검색 & 정보 수집

2"번호 보여줘" → "1번 새 탭"링크 옆 [1][2][3] 오버레이AXUIElement 트리 탐색 → Cmd+클릭 시뮬레이션

5"오른쪽에 메모 앱" + 받아쓰기화면 좌우 분할open -a Notes + bounds 배치 + voice_type
