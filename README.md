# ⌨️ Smart-Homerow: Adaptive Keyboard Interface

> **2026 사혁신 수업 프로젝트 - 김주현**
> **"사용자의 습관을 학습하여 가장 필요한 버튼만 남기는 지능형 인터페이스"**

## 1. 프로젝트 목적 (Objective)
본 프로젝트는 사용자의 작업 패턴을 실시간으로 학습하여, 화면의 수많은 요소 중 **현재 맥락에서 가장 클릭 확률이 높은 버튼에만 단축키 태그를 노출**하는 지능형 제어 시스템입니다. 사용자가 단축키를 자연스럽게 외우도록 유도하여 최종적으로 마우스 없는 컴퓨팅 환경을 구축하는 것을 목표로 합니다.

## 2. 다루는 문제 (Problem Statement)
* **정보 과부하:** 기존 Homerow 툴은 화면의 모든 요소에 태그를 붙여 사용자가 원하는 버튼을 찾는 데 시각적 피로를 유발합니다.
* **불필요한 힌트:** 사용자가 이미 외우고 있거나 거의 쓰지 않는 기능까지 항상 태그가 노출되어 작업 효율을 저해합니다.

## 3. 핵심 접근법 (Approach)
* **EMA 기반 빈도 학습:** 사용자의 클릭 빈도와 최신성을 결합한 지수 이동 평균(Exponential Moving Average) 알고리즘을 통해 버튼별 중요도 점수를 관리합니다.
* **네거티브 피드백 반영:** 시스템이 추천한 단축키를 무시하고 사용자가 마우스로 다른 버튼을 조작할 경우, 추천되었던 버튼의 노출 우선순위를 즉시 낮춥니다.
* **근육 기억(Muscle Memory) 가이드:** 단축키 사용 숙련도가 높아질수록 해당 태그의 투명도를 점진적으로 높여(Fade-out), 힌트 없이도 조작이 가능한 상태로 유도합니다.

## 4. 사용자 경험(UX) 로드맵: 3단계 변화 과정

사용자는 본 서비스를 이용하며 다음과 같은 단계별 경험의 성장을 겪게 됩니다.

### [1단계: 탐색 및 데이터 수집 (초기 설치 직후)]
* **시스템 상태:** 사용자 데이터가 누적되지 않아 주요 후보군에 있는 대부분의 버튼에 태그가 노출됩니다.
* **사용 방법:** `Shift + Command + Space`로 태그를 띄운 뒤, 화면에 보이는 알파벳을 입력하여 조작합니다.
* **경험 변화:** "처음에는 태그가 많아 다소 복잡하게 느껴지지만, 시스템이 나의 클릭 패턴을 수집하기 시작하는 단계입니다."

### [2단계: 최적화 및 적응 (사용 1~3일차)]
* **시스템 상태:** 학습이 진행됨에 따라 자주 쓰는 상위 5~10개의 버튼 위주로 태그가 집중 노출됩니다.
* **피드백 루프:** - **긍정 피드백:** 추천된 태그를 키보드로 입력하면 해당 버튼의 가중치 점수가 상승합니다.
    - **부정 피드백:** 추천된 버튼 대신 마우스를 사용하면, 시스템은 이를 "잘못된 추천"으로 간주하고 다음 노출에서 제외합니다.
* **경험 변화:** "화면이 깨끗해집니다. 내가 누르려던 버튼에만 태그가 붙어 있어 인지적 부하 없이 매우 빠르게 조작할 수 있습니다."

### [3단계: 숙련 및 투명화 (사용 1주일 이후)]
* **시스템 상태:** 사용자가 완벽히 외운 단축키의 태그는 점차 투명해지거나 사라집니다.
* **최종 단계:** 화면에 시각적 힌트가 없어도 사용자는 특정 버튼이 어떤 키와 매칭되는지 이미 알고 있습니다.
* **경험 변화:** "시각적 힌트 없이도 손가락이 먼저 반응합니다. 마우스에 손을 대지 않고도 모든 작업을 수행하는 진정한 파워 유저의 경험을 제공합니다."

## 5. 기술적 구성요소 (Technical Components)
* **UI Analysis:** Mac Accessibility API를 활용한 실시간 UI 트리 구조 분석 및 좌표 추출.
* **Local Learning Engine:** 외부 서버 연결 없이 로컬에서만 작동하는 경량화 학습 모델 (개인정보 및 보안 최적화).
* **Tracking Logic:** 마우스 클릭 좌표와 UI 요소 좌표를 매칭하여 사용자의 실제 선호도를 분석하는 트래킹 엔진.
