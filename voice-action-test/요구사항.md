# 문서 정리 도우미 요구사항

이 문서는 요약·항목 추출·파일 저장 테스트를 위한 가상 요구사항이다.

## 필수 기능

1. 지정한 텍스트 파일의 내용을 읽는다.
2. 원문에 근거해 요약하고 없는 정보는 '정보 없음'으로 표시한다.
3. 후보 파일이 여러 개면 본문을 읽기 전에 사용자의 선택을 받는다.
4. 파일 쓰기·삭제는 호출별로 승인받는다.
5. 최근 승인된 파일 변경을 Undo로 되돌린다.

## 이번 범위에 없는 기능

- 마이크 입력과 음성 전사
- 파일 이동과 이름 변경
- 폴더 생성 및 재귀 삭제
- 웹 페이지 클릭·로그인·제출

## 인수 조건

- 읽기 요청은 파일 내용을 바꾸지 않는다.
- 쓰기 요청을 거절하면 대상 파일을 만들거나 덮어쓰지 않는다.
- 원문에 없는 일정, 담당자, 비용을 요약에 추가하지 않는다.

## 미정

실제 배포일, 예산, 개발 담당자는 아직 정하지 않았다.
