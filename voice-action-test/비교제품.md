# Lumen Band 제품 소개

Aura Watch와 비교하는 연습을 위한 가상 제품 자료다.

| 항목 | 정보 |
|---|---|
| 배터리 | 최대 7일 |
| 충전 | 20분 충전으로 하루 사용 |
| 건강 기록 | 심박 측정 |
| 운동 관리 | 운동 40종 지원, 자동 인식 여부는 정보 없음 |
| 낙상 감지 | 지원하지 않음 |
| 가격 | 89,000원 |

## 설명

가벼운 활동 기록에 초점을 맞춘 손목 밴드다.
산소포화도 측정 여부, 방수 등급, 화면 크기, 출시일은 제공되지 않는다.

## 비교 시 주의

두 제품에서 같은 항목의 정보가 있어야 수치로 비교한다.
Aura Watch의 가격은 product.md에 없으므로 가격 차이를 계산할 수 없다.
지원 운동 수와 자동 인식 여부는 서로 다른 항목이다.
