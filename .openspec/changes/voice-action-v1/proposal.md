# Proposal: Voice-Action AI v1.0

> 상태: PROPOSED  
> 작성일: 2026-06-09  
> 범위: 초기 구현 — 음성 명령 → 파일 정리 전체 파이프라인

---

## 목표

R-cmd(오른쪽 커맨드 키) 하나로 음성 명령을 받아 macOS 파일 시스템을 정리·분류하는 로컬 전용 AI 에이전트를 구현한다.

## 해결하는 문제

- 파일 정리를 위해 앱을 전환하거나 CLI를 열어야 하는 컨텍스트 전환 비용
- Finder 수작업의 반복성 및 실수 위험
- 음성으로 의도를 표현하고 싶지만 도구가 없음

## 사용 흐름 요약

1. 어떤 작업 중에도 **R-cmd 길게 누름** → 마이크 녹음 시작
2. "다운로드 폴더 PDF Documents로 이동해줘" 발화
3. **R-cmd 뗌** → 녹음 종료, 자동 처리 시작
4. **미리보기 패널** 표시: 이동/삭제 계획 목록
5. [실행] 클릭 → 파일 정리 완료 → "14개 이동, 2개 삭제" 배너

## 핵심 제약

- **영구 삭제 금지**: 모든 delete는 `~/.Trash` 경유
- **로컬 전용**: 클라우드 배포 없음
- **단일 LLM 호출**: 명령당 Claude Haiku 1회
- **확인 게이트**: delete 항목 포함 시 [실행] 클릭 필수
- **macOS 13+ 전용**: Python 3.11+

## 성공 기준

| 항목 | 목표 |
|------|------|
| R-cmd → 완료 전체 지연 | 10초 이내 |
| LLM 호출 횟수 | 명령당 1회 |
| 파일 이동 정확도 | 90% 이상 |
| 영구 파일 손실 | 0건 |
